# Contributing

Thanks for helping improve YT Dual Subs.

## Development

The extension uses plain JavaScript and CSS and does not require a build step or dependency installation. Load the repository as an unpacked extension in Chrome or Edge, then run the repository's Node checks before opening a pull request.

## Pull requests

- Keep each change focused and explain the user-visible behavior.
- Add or update a regression test when changing caption loading, translation, storage, keyboard shortcuts, or export behavior.
- Use synthetic captions and public video references only; never commit credentials, cookies, browser profiles, private URLs, or personal data.
- Document browser-specific behavior and limitations when a change depends on Chrome or Edge APIs.
- Check the English and Chinese README when installation, privacy, permissions, or supported behavior changes.

## Issues

Include the browser, extension version, caption language, translation mode, and concise reproduction steps. Remove personal information and use a public video URL only when it is needed to reproduce the problem.

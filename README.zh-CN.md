# YT Dual Subs（YouTube 双语字幕）

> 在 YouTube 上把**原文 + 译文**同时显示成**单层、不重叠**的字幕，并且按整句切换、不再逐词闪烁。

**English → [README.md](README.md)**

一个完全独立、开源的 **Manifest V3** 扩展。它读取视频真正的字幕轨、即时翻译，再把两种语言渲染在一个可自定义、可拖动的图层里——没有重叠，也没有逐词跳动。

---

## 功能特性

- **双语单层。** 原文和译文各占一个区域,长句会自动换成多行;YouTube 自带字幕层被隐藏,两者永不重叠。
- **整句切换,不抖动。** 把相邻的带时间轴字幕片段合成句子,从句首显示完整原文和译文;长停顿或过长、无标点的内容会安全拆开。无法预读字幕轨时仍使用屏幕字幕回退模式。
- **过滤声音提示。** 显示时去掉 `[musik]`、`[音乐]` 等常见括号音效标签，保留同一条字幕中的对白和普通括号内容；导出的 SRT 仍保留原始字幕。
- **两套翻译引擎、三种模式。** 默认使用 YouTube 的整轨翻译；逐句模式使用 Google 免费接口；可选“快速显示”会在等待 YouTube 时先向 Google 翻译当前句。
- **高度可定制。** 每一行的字体、字号、文字色、背景色 + 透明度、描边、行间距、上下顺序都能单独设置,弹窗里有实时预览。
- **可拖动。** 抓住手柄把字幕框拖到画面任意位置,会记住;双击手柄复位。全屏下也可用。
- **一键开关。** 播放器控制栏里有个按钮,一键开/关整个插件(连带 YouTube 的 CC)——遇到自带硬字幕的视频特别方便。
- **导出 SRT。** 在弹窗里把当前视频的字幕导出成标准 `.srt` 文件——可选原文、译文或双语。
- **稳健。** 支持 YouTube 单页跳转;万一取 cue 失败会自动回退到读屏幕字幕文本;并会自动帮你打开 YouTube 字幕。

- **刷新扩展不再报错。** 扩展重载或更新时,如果 YouTube 标签页还开着,旧脚本不会再往错误面板里刷 `Extension context invalidated`:它会发现上下文已失效,静静地停掉自己的循环和监听,并用内置文案继续显示。刷新标签页即可用上新版本。
- **看过的视频秒开。** 本次浏览会话里打开过的视频,字幕 cue 会留在内存中;再回到该视频时立刻显示,同时后台仍会重新取一遍最新字幕。
- **字幕同步微调。** 字幕比声音早一点或晚一点时,用弹窗里的「字幕同步」滑杆最多前后挪 2 秒;导出的 SRT 时间轴不受影响。
- **状态提示行。** 弹窗顶部会显示当前标签页的状态:在用 YouTube 字幕轨、在用 Google、还在等待、已加载多少句、免费接口是否正在限流冷却,以及当前生效的版本号。
- **静默省电。** 视频暂停或标签页在后台时不再重复渲染;拖动进度条或改设置后会立刻重绘一次。
- **学习模式:复读 + 降速。** 可以把当前句重放 2、3、5 次或一直循环,并以 0.75× / 0.6× / 0.5× 播放,停止复读后自动恢复原速。`Alt+Shift+S` 随时复读当前句。
- **词高亮只加底框,不再跳词。** 整句始终完整显示,正在读到的那个词只是多一个柔和的底色框,便于跟读。词级时间只有自动生成的字幕才有;作者上传的字幕只能整句显示。
- **先听懂,再对照。** 译文行可以「始终显示」「鼠标移到播放器上时显示」或「只在你按键时显示」(`Alt+Shift+U`)。
- **更早出字幕。** 会先根据播放器自己的字幕轨列表提前取一次字幕轨,让第一句更早出现;如果这次猜测已失效,会静默丢弃并由正常抓取流程接手。
- **所有开关都在弹窗里。** 弹窗新增「当前视频」卡片:复读当前句、显示/隐藏译文、上一句、下一句,和快捷键完全等效,不用离开弹窗。卡片还会列出浏览器实际分配的按键,并一键打开改键页面。
- **字幕开关交给你。** 关掉「自动打开 YouTube 字幕」后,扩展不会再动播放器上的字幕按钮,由你自己选轨;双语覆盖层照常显示。
- **全屏时悬停也能显示译文。** 显示逻辑改为跟随鼠标实际位置,不再依赖 `:hover`(播放器占满窗口时它永远为真)。
- **多语言视频学习。** 弹窗会显示当前原文字幕轨与译文目标语言；可搜索整段视频的句子、按句跳转、收藏难句、回放并遮住译文自测。学习预设会启用原文、悬停显示译文和 0.75× 复读速度，并保留当前目标语言。
- **字幕文字可选。** 在视频画面上可拖选原文或译文并复制，选词时不会误触播放器暂停；悬停译文在鼠标离开播放器或浏览器窗口时立即隐藏。
- **悬停查词。** 鼠标在原文单词上稍停约 0.4 秒，即用现有 Google 翻译接口查询该词并显示小卡片；移动到别的词会取消旧结果，重复查询会使用本页缓存。德语词另有“德语助手详查”链接，点击后才打开其官网词条。单词直译可能与原句语义不同，遇到词形变化或固定搭配请结合原句与词典判断。此功能可在「学习」中关闭。

## 工作原理

YouTube 的字幕来自 `/api/timedtext` 接口,如今每次请求都需要一个 **proof‑of‑origin token(`pot`)**。扩展自己直接去拉字幕 URL 会拿到**空响应**。所以做法是:

1. 一个运行在页面主世界(MAIN world)的脚本 `inject.js` **被动**监听页面网络(XHR、`fetch`、Resource Timing),抓取**播放器自己**发出的、已经带着有效 `pot` 的那条 timedtext 请求。
2. 用这条 URL 以 `json3` 取原文 cue,再加 `&tlang=` 取 YouTube 的译文——两者逐句对齐。配对时还会校验时间戳:片段起点相差超过约 1.2 秒就不采用,该句改走整句翻译路径,避免出现看似合理却错行的译文。
3. `content.js` 先把相邻的 cue 合并为显示用句子,再按 `video.currentTime` 驱动覆盖层;原始 cue 保留给 SRT 导出。
4. 万一取 cue 失败,自动回退为直接读取屏幕上的字幕文本。

## 安装(加载已解压的扩展)

1. 到 [Releases 页面](https://github.com/Gythiro/yt-dual-subs/releases/latest)**下载最新版 ZIP** 并解压。*(喜欢命令行也可以直接 `git clone`。)*
2. 打开 `chrome://extensions`。
3. 打开右上角的**开发者模式**。
4. 点击**加载已解压的扩展程序**,选择解压后的文件夹。
5. 打开任意有字幕的 YouTube 视频——字幕会自动出现(扩展会替你打开 CC)。

支持 Chrome / Edge 等 Chromium 浏览器。需要 Chrome 111+(用于主世界 content script)。

**更新插件:** 在 `chrome://extensions` 上点击插件卡片里的刷新按钮,然后刷新已经打开的 YouTube 标签页——旧标签页会继续用加载时那份脚本,直到刷新为止。

## 使用

- **工具栏图标** → 设置弹窗:目标语言、翻译引擎、上下顺序、位置、行间距,以及每一行的样式,均带实时预览。
- **控制栏按钮**(齿轮旁边那个字幕框图标):一键开/关。**蓝色 = 开,灰色 = 关。**
- **Alt+Shift+Y**：只切换译文字幕的显示与隐藏，原文字幕保持显示。如果快捷键未分配，可在 `edge://extensions/shortcuts` 中设置。
- 鼠标移到播放器上,字幕框左上角会出现**拖动手柄**;拖动可移动位置,**双击手柄复位**。
- **导出**(弹窗 →「导出字幕」):把字幕下载成 `.srt` 文件——可选原文、译文或双语。

- **字幕早/晚了一点?** 弹窗 →「字幕同步」:最多前后挪 2 秒。只影响画面显示,导出的 `.srt` 仍用原始时间轴。
- **字幕没出来?** 弹窗顶部的状态行会说明:当前用的是 YouTube 字幕轨、Google 接口,还是仍在等待;已经加载多少句;免费接口是否正在冷却。
- **Alt+Shift+S** 复读当前句(按设置的速度降速),再按一次停止;**Alt+Shift+U** 在「只按键显示」模式下显示/隐藏译文行。两个快捷键都可以在 `edge://extensions/shortcuts` 里改。
- **学习设置**(弹窗 →「学习」):复读次数、复读速度、逐词高亮底框、译文显示方式。
- **当前视频**(弹窗 →「当前视频」):四个按钮对应四个快捷键——复读当前句、显示/隐藏译文、上一句、下一句。「上一句」在句中按下会先回到本句句首,在句子刚开始的一秒内按下则退回上一句。改键只能由浏览器完成,所以卡片会直接跳到那个页面并显示当前分配的按键。关掉「自动打开 YouTube 字幕」可自己选字幕轨,覆盖层照常工作。
- **视频语言学习**(弹窗 →「视频语言学习」):先在 YouTube 字幕菜单选想学习的原文轨，再在「目标语言」选择译文语言。列表外的语言可选「其他语言代码…」，输入如 `nl`、`tr`、`uk` 或 `pt-BR`。「逐句浏览」支持搜索、跳转、收藏；「收藏复习」默认遮住译文，可回听并标记掌握。收藏存在当前浏览器，不随设置同步；可用「导出收藏／导入收藏」备份或恢复，导入会合并而不覆盖现有记录。「重置字幕设置」不会删除收藏。
- **单词查询**(弹窗 →「学习」→「鼠标停在原文单词上时查词」):将鼠标放到视频原文字幕里的单词上，稍停后出现译义卡片；拖选字幕时不会发起查词。德语助手网页只在点击“详查”后打开，不会因鼠标掠过单词自动打开外部站点。
- **双语 SRT 完整性。** 导出时也校验原文和译文的时间戳。如果有未对齐或缺失的口语句，扩展会停止双语/译文导出并报告缺失数量；原文 SRT 仍可导出。

## 两套翻译引擎

| | 整句翻译(`tlang`)— 默认 | 逐句翻译(`gtx`) |
|---|---|---|
| 来源 | YouTube 服务端整轨翻译 | Google 免费翻译接口 |
| 对齐 | 按片段配对，并校验时间戳 | 按显示句逐句翻译 |
| 适合 | YouTube 提供整轨译文时 | YouTube 无法翻译该轨，或你更喜欢 Google 的措辞 |
| 备注 | 视频不可翻译时自动回退到 `gtx` | 非官方接口,重度使用可能被限流 |

逐句翻译会把字幕轨的语言(例如 `de`)显式告诉 Google,而不是交给接口自动判断——对只有几个词的短句,自动识别常常缺少依据;只有在拿不到轨语言时(屏幕字幕回退)才退回自动识别。缓存同样按“源语言 + 目标语言 + 原文”区分,同一句话不会因为来源不同而串用译文。

原文轨不限德语；英语、西班牙语、日语、阿拉伯语等都沿用同一取轨和翻译流程。自定义目标语言代码允许尝试更多语种，但视频须有可用字幕，译文是否可得仍取决于 YouTube 或 Google 翻译服务；不能保证每一种语言和每一个视频都可翻译。

**快速显示**（可选）：等待 YouTube 整轨译文时，将当前句发送到 Google 接口先显示；YouTube 译文到达后，后续句子使用 YouTube。已显示的当前句不会被改写。Google 返回 429 等错误时仍等待 YouTube。这一模式即使 YouTube 最终可用，也会把等待期间的当前句发送给 Google。

每次 Google 请求都有超时保护:8 秒没有响应的请求会被中止,并且只重试一次——否则一个卡住的请求会一直占着有限的并发额度。被限流(HTTP 429)时不会重试,而是依次退避 20 秒、60 秒、3 分钟,期间继续使用 YouTube 提供的译文,第一次成功返回即清除等待。

## 已知限制

- 需要真正的字幕轨。**烧录进画面**的硬字幕(画进视频像素里的)无法隐藏——这类视频用控制栏按钮把覆盖层关掉即可。
- Google 回退用的是非官方接口,无 SLA,重度使用可能被限流。
- 依赖 YouTube 当前行为;YouTube 大改版时可能需要更新选择器。

## 隐私

无统计、无追踪、无账号。默认模式优先使用 YouTube，翻译不可用时会回退到 Google；逐句模式使用 Google；“快速显示”同时使用两者，并将等待期间的当前句发送给 Google。启用悬停查词时，只在鼠标停留约 0.4 秒后向 Google 发送当前单词；“德语助手详查”仅在点击时把该词打开到其官网，不自动发送整句，也不新增站点权限。设置保存在 `chrome.storage.sync`，收藏句子保存在 `chrome.storage.local`，不会自动同步。卸载扩展会清除本地收藏，卸载前请导出备份。

## 开发

纯原生 JS/CSS,无需构建、无依赖。

| 文件 | 作用 |
|---|---|
| `inject.js` | 主世界嗅探:抓取播放器带 `pot` 的 timedtext URL,取 cue + 译文 |
| `content.js` | 覆盖层、cue 引擎、拖动、控制栏开关、读屏回退 |
| `background.js` | 翻译 service worker(Google 接口) |
| `popup.html/.css/.js` | 带实时预览的设置界面 |
| `study.js` | 逐句浏览、本地收藏与复习界面 |
| `content.css` | 覆盖层样式 + 隐藏原生字幕 |

### 测试

`node tests/<名称>.test.cjs` —— 不需要框架、不需要安装。测试用 `node:vm` 加载**真实的** `content.js`、`inject.js`、`background.js`,配上仿真的 YouTube 页面、弹窗和扩展 API,因此断言的是实际发布的源码,而不是复制出来的逻辑。`tests/context-invalidated.test.cjs` 会让这套仿真 API 像真实重载那样抛出 `Extension context invalidated`,这样 `content.js:25` 上报的崩溃就不会悄悄回归。`tests/study.test.cjs` 覆盖复读、降速、逐词底框、悬停查词与旧请求失效、译文显示方式和上/下一句按钮;`tests/startup.test.cjs` 覆盖提前取字幕轨,以及猜测失效时不会误切到读屏回退。

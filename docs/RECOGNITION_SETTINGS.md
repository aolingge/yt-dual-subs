# 本机识别设置与校正（3.12.6）

## 启用

1. 使用更新后的 `E:\codemain\deautschapp` 源码启动桥；旧 EXE 不包含这些功能。
2. 在 `edge://extensions` 重新加载本扩展，刷新视频标签页。
3. 在扩展面板填写本机地址和令牌，点击“检查连接”。令牌只存在本机存储，不进入同步设置。
4. 展开“识别模型与术语”，读取配置。这里只能选择桥预先登记的本机模型，网页不能提交模型文件路径。
5. 停止识别后再切换模型、简繁字形、术语或整句翻译选项；应用成功后，在新会话生效。

只有**当前视频或分 P 已可靠确认没有原生字幕**，才能开始识别。字幕加载中、未知、失败、其他语言的原生字幕，都不能绕过检查。原生字幕出现后停止识别；换视频、跳转与倍速变更不会沿用旧时间线结果。

## 如何选

- **Small**：资源较少；**Turbo**：本轮固定对话样本总错误率较低，但并非所有样本都更好。模型已下载到本机；切换不会自动联网下载。
- **设备**：尚未加载时显示“未加载，启动识别时加载”；模型实际加载后显示 CUDA 或 CPU。GPU 回退提示表示使用 CPU，不能据此假设 GPU 仍在运行。
- **简体/繁体**：统一显示字形，并保留原始识别文字；字形转换不修复听辨错误。
- **术语**：按实际视频填写人名、地名、专业词。默认留空；无关术语可能影响结果。
- **整句翻译**：可组合最多三段未完句的原文，给出共享整句译文，并标注“整句译文”。默认关闭；不会猜测裁剪译文来匹配单段。

## 核对、校正、重新识别

“识别待核对”是解码信息的启发式提示，**不是正确率百分比**。没有提示也不保证正确；缺少模型分数时同样需要核对。

打开字幕列表，点击“校正”，可以修改原文及译文。校正不会被迟到的识别结果覆盖；修改文本会清除旧词时间，避免错误的逐词高亮。校正保留到当前页面关闭；需要长期保存时请收藏或导出。

“重新识别此段”仅使用最近的内存音频：最多八个片段、合计六十秒；过期、停止或跳转后不能重试。重试采用更宽搜索，但不保证更准。成功提交重试后清除该段人工校正；删除的旧句子会从画面和列表消失。桥关闭后不保留这些音频片段。

## 排队与耗时

识别与翻译分别排队；原文可以先显示，译文稍后补齐。面板显示两个队列长度、跳过计数，以及最近最多 128 次测量的识别/翻译 P95 耗时。P95 指处理耗时分布，不等于从说话到字幕显示的总延迟。队列满时跳过最旧的待处理任务，译文失败仍保留原文。

桥接会话使用单调时钟清理：默认连续两小时没有请求会被回收，单个会话最长六小时；正在识别或翻译的工作会等到空闲后再清理。过期会话返回明确的“未找到”状态，不保留音频片段。

## 本轮测量边界

### 音频输入状态

面板显示“已暂停”“等待信号”“已收到信号”“持续静音或信号过低”“未收到采集数据”“音频处理已暂停”或“等待视频时间位置”。有信号只说明收到音频，不代表模型已识别到语音；音乐也可能产生信号。

播放中约八秒没有达到 16 位 PCM 量级的信号，显示持续静音提示；约三秒未收到数据，显示采集数据缺失。这些状态不会自动停止识别或调整视频音量；正常短停顿不会触发持续静音提示。暂停、恢复或时间线变化后重新观察。如果音轨结束，停止采集但保留已显示字幕，可以重新开始。

### 准确性与采集验证

63 项固定案例包含 36 段真人对话、9 段朗读及其 18 个噪声/音乐副本。中文对话 CER 从 20.25% 降至 14.72%，中英混合从 25.68% 降至 20.27%；五个单项退步。缺少德语自然对话、人工词边界与翻译质量评分，不能声称所有场景准确率已提高。

测试浏览器使用独立配置及 `--mute-audio`。真实 tabCapture 已启动，但此机器的无界面及隐藏窗口静音 Edge 均返回零值音频，因此未证明真实页面非零采集，也不能将原因仅归于无界面模式。另以解码后的真人录音验证了真实 AudioWorklet、桥、模型、译文、校正与重试；输入替代不应被当作真实标签页采集通过。

3.12.4 诊断进一步确认：视频自身解码后的音频峰值非零，真正 tabCapture 返回的音频仍为零。失败点已缩小到解码之后的捕获链路；无头模式已启用自动播放策略，但确切原因尚未确定，不能以输入状态检查通过代替非零采集通过。

详见 [准确性说明](ACCURACY.md) 与 [版本记录](releases/v3.12.4.md)。
## 目标语言边界

扩展界面的 `targetLang` 同时决定识别字幕的显示目标。本机 OPUS 桥接当前只
保证输出德语 `de`。如果 YouTube 目标仍是 `zh-CN`，扩展会在开始采集前明确拒绝
本机识别，不会把德语静默当成中文；切换到德语后才允许启动。

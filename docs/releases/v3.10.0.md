# v3.10.0 — Audio-aligned word highlighting

**Source update on `main`.** The packaged GitHub release remains v3.9.0. Use the [current source ZIP](https://github.com/aolingge/yt-dual-subs/archive/refs/heads/main.zip) or a checkout. [Install guide](../../README.md#install) · [Audio alignment](../../docs/AUDIO_ALIGNMENT.md) · [中文](#中文)

- Follow the spoken words even when the captions carry no usable word times. An optional helper on your own machine measures each word's start and end from the video's audio plus the caption text, so the highlight follows the speech instead of a spread-out estimate. German and English, CPU only, model about 360 MB per language, downloaded once.
- The measured times only fill cues that have no caption word times at all. Caption word times keep priority, the sentence and its translation text are never changed, SRT exports stay as YouTube delivered them, and a weak or mismatched alignment is discarded instead of shown. Videos that use audio-derived timing say so in the interface.
- Start the helper by double-clicking `tools/Start-AudioAlignment.cmd`, then press 「音频对齐跟读」 in the popup study card. It listens only on `127.0.0.1:8765`, the extension asks for `http://127.0.0.1/*` when you start a job rather than at install, and every result stays in your local cache. No account, API key, paid service, or new extension dependency.
- The helper got sturdier: it now holds its port exclusively, so a second copy exits with a clear message instead of silently splitting one job across two processes (that split produced an `HTTP 400` on audio upload); the launcher no longer reinstalls its Python requirements on every start, waits for `/health` before reporting success, and prints where results are cached and whether that folder is writable; `Stop-AudioAlignment.ps1` now stops every leftover helper.

All **161 source regression tests** and **7 helper tests** passed. On synthetic German speech whose word boundaries are known, the local model's word starts were within **61 ms on average and 84 ms at worst** of the reference times — reference times come from the system speech engine's own word events, not from live YouTube speech. In isolated Edge with controlled captions and this real model, the extension requested the local permission, analysed one uploaded German utterance (17 words), switched that cue to `audio` word timing, highlighted the expected word at four sampled positions with real seeks (`Wir`, `Ich`, `Danach`, `Pause`), kept the sentence and translation text unchanged, showed no word inside the measured pause, restored the audio timing after a page reload, and reported no page errors; the mocked video had to advertise byte ranges for the browser to accept seeks, and headless Edge still auto-denies a permission prompt, so that run used an unpacked copy whose manifest declares `http://127.0.0.1/*` as a required host permission.

Anonymous live-video checks are still not possible from this environment, so audio alignment has not been observed on a real YouTube stream. Accuracy depends on captions that match the speech; characters the model cannot place are skipped, and this feature never creates captions for a video that has none.

Reload the extension in its existing unpacked folder and refresh open YouTube tabs to activate the updated scripts.

## 中文

**这是 `main` 分支的源码更新。** GitHub 发行包仍为 v3.9.0；请使用[最新源码 ZIP](https://github.com/aolingge/yt-dual-subs/archive/refs/heads/main.zip)或 Git 克隆。[安装说明](../../README.zh-CN.md#安装) · [音频对齐说明](../../docs/AUDIO_ALIGNMENT.md) · [中文](#中文)

- 字幕没有可靠的词时间时，也能跟着语音走。可选的本机程序用视频音频与字幕文本量出每个词的起止时间，让高亮真正跟着说话节奏，而不是把整句平均摊开。支持德语和英语，只用 CPU，每种语言模型约 360 MB，只需下载一次。
- 量出的时间只填空白的句子。字幕自带的词时间优先，原文与译文文本不会被改写，SRT 导出保持 YouTube 原样；对齐质量差或与字幕不符时直接放弃，不会显示猜测结果。使用音频时间的视频会在界面上标明来源。
- 双击 `tools/Start-AudioAlignment.cmd` 启动本机程序，再在扩展弹窗的学习卡片里点「音频对齐跟读」。它只监听 `127.0.0.1:8765`；权限 `http://127.0.0.1/*` 在你开始分析时才请求，安装时不请求；结果全部保存在本机缓存。不需要账号、API Key、付费服务，扩展本身也不新增依赖。
- 本机程序更稳：端口改为独占，第二个副本会直接退出并提示，而不是把一次任务悄悄拆给两个进程（之前上传音频 `HTTP 400` 正是这样产生的）；启动脚本不再在每次启动时重装 Python 依赖，会等 `/health` 通过再报成功，并打印缓存目录与是否可写；`Stop-AudioAlignment.ps1` 会停掉所有残留进程。

全部 **161 项源码回归测试**和 **7 项本机程序测试**通过。在已知词边界的合成德语语音上，本机模型量出的词起点与参考时间平均相差 **61 毫秒**，最大 **84 毫秒**（参考时间来自系统语音引擎自身的词事件，不是真实 YouTube 语音）。在独立 Edge 中配合受控字幕与真实模型：扩展成功请求本机权限，分析了上传的一段德语（17 个词），把该句切换为音频词时间，在四个抽样位置用真实跳转验证高亮落在正确的词上（`Wir`、`Ich`、`Danach`、`Pause`），原文与译文文本未变，停顿处没有高亮，刷新后又恢复音频时间，页面没有错误；模拟视频必须声明支持字节范围浏览器才接受跳转，且无头 Edge 仍会自动拒绝权限弹窗，因此该轮使用了解压副本并把 `http://127.0.0.1/*` 写为必需主机权限。

受环境限制仍无法做匿名真实视频检查，因此音频对齐尚未在真实 YouTube 流上验证。效果取决于字幕文本是否与语音一致，模型无法对齐的字符会被跳过，本功能也不会为没有字幕的视频生成字幕。

在原来的解压目录重新加载扩展，再刷新已打开的 YouTube 标签页，使新脚本生效。

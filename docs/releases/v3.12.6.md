# v3.12.6

## 字幕与性能

- 逐词跟读继续显示完整句子；小于 120ms 的单词不做闪烁式强调，普通强调改为较轻的背景和下划线。
- 高亮文字默认改为白色，适配淡背景；仅旧版完整默认配色进行一次性迁移，其他自定义配色与之后的手动调整保留。设置预览与播放器采用同样的淡背景和下划线。
- 保存 `rawOriginal`，显示清理与原始识别文本分开；回归检查覆盖德语引号、逗号和句末标点。源字幕本来没有标点时，本版本不凭空补写标点。
- 单词时间定位改为二分查找，保留真实停顿、前后跳转和极短单词的处理规则。
- 视频语速分析按字幕列表缓存；音频对齐与人工修正明确使缓存失效。
- 没有新增字幕的识别轮询复用原字幕列表，避免全表建索引、复制和排序；重复或过期修订也避免复制和排序。
- 识别客户端持续保存删除记录，防止空轮询或迟到的旧修订把已删除字幕重新加入。
- 弹窗和字幕列表共享同一标签页的正在执行的状态查询；查询完成后立即释放，不持久缓存状态。
- 状态刷新任务不重叠；学习页隐藏时停止定时发消息，重新显示时立即刷新。

## 验证

验证清单及边界见 [性能检查](../PERFORMANCE.md)。独立浏览器测试默认静音，不修改系统音量。真实无头 Edge `tabCapture` 全零样本的问题仍按采集限制单独记录；本次性能改动不能证明该问题已解决。

# v3.8.1 — Multilingual video study

[Download the extension ZIP](https://github.com/aolingge/yt-dual-subs/releases/download/v3.8.1/yt-dual-subs-3.8.1.zip) · [Install guide](../../README.md#install) · [中文](#中文)

This is the first packaged release of the enhancements maintained in this repository, based on the original YT Dual Subs extension.

## What is included

- Multilingual source captions and custom translation target codes.
- Hover word translation, selectable subtitles, and a German Assistant dictionary link.
- Sentence search, replay, local saved cards, translation-hidden review, and JSON backup/import.
- Adaptive windowed/fullscreen layout and draggable left/right width grips.
- Original-first startup, parallel caption/translation loading, upcoming-sentence translation, and clock-checked late responses.
- Original, translated, and bilingual SRT export with translation-completeness checks.

## Install or update

Extract the ZIP, then load its **yt-dual-subs** folder using your browser's **Load unpacked** option. For an existing installation, replace files in the same folder, reload the extension, and refresh YouTube tabs. Back up saved sentences before uninstalling.

## Verification and limits

The shipped scripts passed **110 source-level regression tests**. Isolated Edge fixture checks exercised lookup, selection, responsive layouts, width persistence, and startup/synchronization; a live Google translation request also succeeded. These checks do not guarantee every live YouTube video or provider response time. Videos need available captions; the Google endpoint is unofficial and can be rate-limited. See [privacy details](../PRIVACY.md).

## 中文

这是本仓库增强功能的第一个安装包版本，基于原版 YT Dual Subs 继续开发。

### 主要功能

- 多语言原文字幕与自定义译文目标语言代码。
- 原文单词悬停查译义、字幕拖选复制、德语助手详查链接。
- 逐句搜索、回放、本地收藏、遮住译文复习，以及 JSON 备份与导入。
- 普通窗口与全屏自适应，字幕框左右边缘可拖动调整宽度。
- 原文先显示、原文与译文并行加载、提前翻译后续句子，并在迟到译文返回时重新核对视频时间。
- 原文、译文与双语 SRT 导出，检查译文完整性。

### 安装与更新

下载 ZIP 并解压，在浏览器扩展管理页通过**加载已解压的扩展**选择其中的 **yt-dual-subs** 文件夹。更新时覆盖同一文件夹、重新加载扩展，再刷新 YouTube 页面；卸载前请备份收藏。

### 验证范围

当前源码已通过 **110 项回归测试**，独立 Edge 演示页面检查了查词、选词、窗口适配、宽度保存与字幕启动/同步，真实 Google 翻译请求也曾成功。这不代表已验证所有真实 YouTube 视频，也不保证服务响应时间。视频须有可用字幕，Google 非官方接口可能限流。查看[隐私说明](../PRIVACY.md#中文)。

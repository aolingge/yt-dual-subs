# v3.9.0 — Automatic word highlighting across caption tracks

[Download the extension ZIP](https://github.com/aolingge/yt-dual-subs/releases/download/v3.9.0/yt-dual-subs-3.9.0.zip) · [Install guide](../../README.md#install) · [中文](#中文)

## What's new

- Automatically prefer original caption word times, then try reliable matches from a same-language automatic caption track. Your selected original text and translation remain intact.
- When reliable word times are unavailable, display **Approximate** progress with a visible badge. This is enabled by default and can be disabled in **Study → Use approximate progress when word times are missing**.
- The popup identifies the current sentence's timing source: original, matched automatic track, approximate, or unavailable.
- Keep the complete sentence on screen; highlighting follows the video clock through playback, pause, seek, sync-offset changes, and cached-video restoration.
- Fix loss of the first word when JSON3 omits its zero offset. Preserve original punctuation and spacing across languages; word selection and hover lookup remain available.
- Load optional timing in the background. It does not delay original/translated captions, reset a manually revealed translation, or restart sentence practice.

## Verification and limits

All **129 source-level regression tests** passed. New cases cover multilingual segmentation/casing, invalid/ambiguous timing, asynchronous donor completion, stale config/video results, pause/seek, cache provenance, disabling timing without refetching, and unchanged SRT times. An isolated headless Edge session also checked actual extension rendering with a playing media clock, approximate labels, automatic timing upgrades, word selection/lookup, popup controls/status, and clearance above windowed player controls.

Browser checks use controlled caption/video fixtures; they do not establish live-video coverage or acoustic accuracy. Usable YouTube captions are required. Matched ASR timestamps inherit their source's errors; approximate progress is a sentence-duration reading aid. This release does not capture or transcribe audio and cannot guarantee precise word following on every video. No new permission, API key, local service, model download, or build step is required. See [privacy and permissions](../PRIVACY.md).

For an unpacked installation, update files in the same folder, reload the extension, and refresh YouTube tabs. Back up saved sentences before uninstalling.

全部 **129 项源码回归测试**通过；另用独立 Edge 验证了实际扩展界面、真实媒体时钟、近似标记、自动字幕时间补充、选词查词、设置开关及小窗口控制栏避让。

浏览器检查采用受控字幕与演示视频，不能证明真实视频的覆盖率或语音对齐精度。视频需要提供可用字幕；自动字幕词时间可能有误差，近似跟读只是按句子时长计算的阅读辅助。当前版本没有采集或识别音频，不能保证所有视频精确逐词跟随。无需新增权限、API 密钥、本地服务、模型下载或构建。可查看[隐私与权限](../PRIVACY.md#中文)。

# 3.12.2 — spoken language and recognition timing

Local source update, 2026-10-04. No public release is implied.

- The recognition panel offers automatic detection, Chinese, German and English. A website's language no longer forces a video's spoken language. Stop recognition before changing this selection.
- Final source-word timings are mapped to video time, checked for confidence, order and cue boundaries, and labelled as recognition times. Translation words never inherit source-audio timings. Incomplete or ambiguous text matches fall back to clearly labelled estimates or the complete sentence.
- The companion Deutsch Overlay source bridge now uses existing PyAV/FFmpeg stateful resampling. It preserves the filter between packets, prepends missing audio, flushes the final filter tail and bounds final VAD padding to the real submitted duration.
- Preroll/snapshot coordinates and seek resets are corrected. Automatic language confirmation needs two independent confident final utterances; explicit selection wins. Final decoding adds word timestamps and the associated silence-hallucination option. Beam size remains 3 because a small human benchmark did not justify increasing it.
- Tests run in isolated muted browsers. See [accuracy evidence](../ACCURACY.md) for measured results and limits.

Reload the extension at `edge://extensions` and refresh video tabs. The audio fixes also require restarting a bridge running the updated `E:\codemain\deautschapp` source. An installed older executable does not acquire source changes automatically.

## 中文

- 识别面板可选择自动、中文、德语、英语；不再由网站语言决定视频语音语言。修改选择前先停止识别。
- 最终原文识别词时间转换到视频坐标，核对置信度、顺序及字幕范围，并明确标记来源。译文不套用原文语音时间；无法完整匹配时回退到明确标注的估算或整句。
- 配套源码桥使用现有 PyAV/FFmpeg 保持重采样滤波状态，修正丢包补零位置，刷出最后音频，并限制尾帧补零范围。
- 修正预留片段、临时字幕和跳转清理。自动语言需两段独立且高置信度的最终语句确认；手动选择优先。最终结果启用逐词时间及配套静音幻觉处理。小规模真人对比不支持增加搜索候选，因此保留 3。
- 在扩展页重新加载并刷新视频标签页；音频修复还需重启使用更新源码的识别桥。旧版安装程序不会自动更新。详见[准确性证据](../ACCURACY.md)。

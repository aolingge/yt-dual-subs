# 3.12.1 — safer local study

Source update, 2026-10-04. Requires Chromium 116 or later.

- Bridge credentials move to extension-origin IndexedDB, with committed migration before legacy copies are cleared. This is origin isolation, not encryption.
- Recording commands validate senders, current video/part and reliable caption absence. Startup failure cleans up; a reactivated worker recovers an existing offscreen session.
- Translation requests share concurrency and queue bounds, request deduplication, deadlines and HTTP 429 cooldown. The existing free endpoint remains unofficial.
- Saved-card mutations are serialized, preventing simultaneous saves or imports from overwriting each other. Anki TSV includes stable IDs, escaped original/translation, source links and tags; JSON backup remains available.
- Open **打开常驻学习页面** to keep a selectable transcript and saved sentences tied to the original video tab. **每句结束后暂停** is optional and uses media time, independent of the visual offset.
- Alignment moves to port 8767 and checks service identity, leaving AnkiConnect's default port 8765 available. Restart the helper after updating.
- Packaging includes transitive runtime assets and documentation, creates a new output directory for each run and verifies ZIP contents and SHA256 without deleting previous outputs.
- Isolated browser checks default to muted audio. Real model recognition accuracy, live YouTube caption availability and import into an installed Anki application require separate verification.

Reload the unpacked extension in `edge://extensions`, then refresh existing video tabs. No additional persistent integration or cloud credential is required. See [privacy](../PRIVACY.md), [Anki](../ANKI.md) and [integration choices](../INTEGRATIONS.md).

## 中文

源码更新日期：2026-10-04。需要 Chromium 116 或以上。

- 桥接令牌迁入扩展自身来源的 IndexedDB，迁移提交成功后才清理旧副本。这是来源隔离，不是加密。
- 录音命令核对消息来源、当前视频/分 P 以及可靠的无字幕状态。失败启动会清理；后台重新唤醒可恢复已有的离屏录音会话。
- 翻译请求统一限制并发与排队长度，复用相同请求，设置超时和 HTTP 429 冷却。现有免费接口仍是非官方接口。
- 收藏操作由后台串行合并，避免多窗口同时保存或导入互相覆盖。Anki TSV 包含稳定编号、安全转义的原文/译文、来源时间链接与标签；JSON 备份保留。
- 使用 **打开常驻学习页面** 保持字幕列表与收藏，并绑定原视频标签页。可选 **每句结束后暂停** 使用视频时间，不受字幕显示偏移影响；字幕可以选择复制。
- 音频对齐改用 8767 并验证服务身份，释放 AnkiConnect 默认 8765 端口。更新后重启辅助程序。
- 打包完整包含运行文件及文档，每次创建独立输出目录，检查 ZIP 清单和 SHA256，不删除已有输出。
- 隔离浏览器测试默认静音。真实模型识别质量、真实 YouTube 字幕可用性及已安装 Anki 的导入仍需单独验证。

在 `edge://extensions` 重新加载解压缩扩展，再刷新已打开的视频页面。无需新增常驻整合服务或云端凭据。参见[隐私](../PRIVACY.md)、[Anki](../ANKI.md)和[整合方案](../INTEGRATIONS.md)。

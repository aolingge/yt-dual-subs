# 3.12.3 — 本地模型控制、核对与分段重试

本机源码及可加载包更新，2026-10-04；没有公开发布。

- 新增经过认证的本机模型配置：登记的 Small/Turbo、设备状态、简繁字形、分语言术语、可选整句翻译。运行或排空会话期间拒绝切换。
- 识别与翻译分别使用有上限的工作队列，先显示原文；面板显示队列、跳过任务及处理耗时 P95。
- 新增“识别待核对”、原文/译文校正及最近内存音频单段重试。校正保留原始识别、清除旧词时间；迟到结果不覆盖人工修改。重试删除的字幕完整清除。
- 修复捕获开始时未获得视频时间位置的竞态。原生字幕可用性独立于识别字幕判断，其他语言原生轨道不授权 ASR。
- YouTube 的空 JSON3 请求可重试实际观察到的原始签名 URL；保留播放器自身读取，限制重试次数，不记录签名 URL。
- 63 项真人/噪声测量提供可复现的来源、许可及逐项结果；不将字体转换或时间戳覆盖率称为声学准确率。

参阅 [中文使用说明](../RECOGNITION_SETTINGS.md)。重载扩展并刷新视频页，还需重新启动新版源码桥。已安装旧 EXE 不会自动获得源码改动。

## 验证限制

独立 Edge 的实际 `--mute-audio` 已核对。真实标签页采集成功启动但返回零样本；直接解码真人录音的测试验证了后续真实音频处理与界面。另一次真实 YouTube/Bilibili 检查观察到画面原文与译文；YouTube 出现的是广告内容，因此不代表目标视频完整原生字幕轨已验证。真实全屏、德语自然对话及人工翻译/逐词时间评分未获完整验证。

# v3.9.1 — Subtitle recovery and reliable settings saves

**Source update on `main`.** The packaged GitHub release remains v3.9.0. Use the [current source ZIP](https://github.com/aolingge/yt-dual-subs/archive/refs/heads/main.zip) or a Git checkout to install this update. [Install guide](../../README.md#install) · [中文](#中文)

- Set the spoken-word highlight's background color, text color, and opacity. Defaults use a 95% opaque gold background and dark text.
- Reuse successful player caption responses, including JSON3/XML word times. Recover transient full-track failures without reloading the page, and allow slower player initialization.
- Reduce the pending-track translation grace from 1.5 seconds to 0.35 seconds. Translation continues while paused. Native fallback merges growing text requests and retains translated prefixes with an ellipsis.
- Fix `MAX_WRITE_OPERATIONS_PER_MINUTE` errors caused by sliders and color pickers. Stage settings locally for immediate use and safe popup closure, then batch sync writes at least 2.5 seconds apart. Preserve pending values during quota failures and resume on worker activation.
- Handle storage errors without unhandled Promise rejections, retain saved sentence cards, and protect newer local edits from older sync events.
- Update English/Chinese install, troubleshooting, development, and privacy documentation.

No new permission, dependency, API key, background service, or build step is required. Browser verification uses an isolated Edge profile with controlled captions; it does not establish live-video coverage or guarantee provider latency.

All **150 source-level regression tests** passed. An isolated Edge check exercised **243 rapid input events**, live overlay changes before sync, closing/reopening the popup, and the final persisted settings, with no page errors or unhandled worker rejections. Source tests also cover minute/hour quotas, worker reactivation, older sync events, and preservation of saved cards.

Update files in the same unpacked-extension folder, reload the extension, and refresh YouTube tabs. Clear old errors in the extension manager after updating to distinguish them from new reports. Back up saved sentences before uninstalling.

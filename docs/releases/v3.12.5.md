# v3.12.5

## 本地优化

- 收藏卡片使用稳定的持久 ID，修正文本不会再生成重复卡片。
- 收藏数据保留原始识别文本、不确定状态、原因和人工校正状态。
- 编辑、保存和导出统一使用 2,000 个 UTF-16 码元的原文限制。
- 本地识别协议显式声明翻译目标；采集使用德语中间译文，`zh-CN`、英语及其他目标由现有翻译队列二次转换，桥接译文缺失时不会把原文误发给云端翻译，手动校正也不会被迟到结果覆盖。
- 静音浏览器诊断继续显示真实音频采集状态；本机无头 Edge 的 tabCapture 全零结果仍单独标记，不能误报为真实采集成功。
- 本机桥接会话增加单调时钟 TTL：连续两小时无请求或单会话达到六小时后回收，繁忙识别任务不会被中途终止。

## 验证边界

扩展完整 Node 测试、结构检查和本地 ZIP 打包已验证。真实 `tabCapture` 会话可以启动，但本机无头 Edge 仍未提供非零采集样本；不得把替代 WAV 输入当作真实标签页采集证明。

# v3.8.2 — Preserve spoken-word highlighting

[Download the extension ZIP](https://github.com/aolingge/yt-dual-subs/releases/download/v3.8.2/yt-dual-subs-3.8.2.zip) · [Install guide](../../README.md#install) · [中文](#中文)

- Fixed word timings being discarded from the in-memory video cache. Returning to a previously watched video now resumes the word highlight at the current playback position.
- Original word timings remain available when the translation target changes.
- Added two regression cases for cached-video word highlighting. This fix passed all **112 source-level regression tests**.

Enable **Study → Box the word being spoken** to use the existing feature. It needs real per-word caption timestamps, often provided by auto-generated captions. A sentence-only track still displays whole sentences; this release does not add speech recognition, audio alignment, or estimated word timings.

For an unpacked installation, replace files in the same folder, reload the extension, and refresh YouTube tabs. The demonstration screenshots in the README show the v3.8.1 interface; the controls have not changed in this patch.

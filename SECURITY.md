# Security Policy

## Reporting a vulnerability

Please report security issues privately to the maintainer through GitHub's private vulnerability reporting or by contacting the repository owner. Do not open a public issue for an undisclosed vulnerability.

When reporting, include the affected browser and extension versions, a minimal reproduction, and the permissions or data involved. Use a public video or synthetic caption fixture whenever possible.

Do not include credentials, cookies, browser profiles, private URLs, personal data, or private logs. Remove identifying information before attaching screenshots or traces.

## Scope

The extension runs in the user's browser and relies on caption and translation providers described in the README. Reports about provider availability, rate limits, or third-party service behavior should include enough evidence to distinguish provider failure from extension behavior.

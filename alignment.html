音频对齐跟读

用视频原文和音频补出词时间，整句保持显示。支持德语和英语；模型在本机运行。

当前视频

开始分析

从当前观看位置优先处理。首次需下载约 360 MB 的模型；之后可复用模型和词时间。分析期间可以继续看视频。

本地文件必须与当前视频对应，并从视频的 0:00 开始。匿名音频获取失败时可用此方式；文件只交给本机程序。

准备本机处理程序

在扩展文件夹中双击 tools → Start-AudioAlignment.cmd。它会准备独立 Python 环境并启动本机程序；需要 Python 3.10+ 和 FFmpeg。首次下载完成后，回到此页开始分析。

此功能只连接 127.0.0.1；字幕和音频在本机处理。程序会从 YouTube 获取公开音频、从 Hugging Face 下载模型，不读取浏览器登录信息。

查看使用说明

音频对齐仍可能有误差。原文与声音不一致、数字或低置信度的句子会保留原有跟读方式。保持此页打开可接收新结果，已保存的结果刷新视频后仍可使用。
